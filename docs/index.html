Pull requests reviewed, fixed and unblocked by AI.
You make the final call.

Three skills work together on your GitHub pull requests. One reviews. One fixes, with a test that fails first. One resolves merge conflicts. Each comment says who wrote it, and nothing merges without you.

Three skills, one pull request

Each skill does one job and says so in its report. They never call each other. They talk through the pull request itself.

🔍 pr-reviewer

Reviews the diff

Read-only agents check the change from several angles. Every finding is checked before it is shown. One verdict: PASSED or BLOCKED.

🔧 pr-fixer

Fixes what was found

Reproduces each finding, writes a test that fails first, fixes it, and posts a checklist with the evidence for every box.

🔀 pr-merge-fixer

Resolves conflicts

Merges the base branch in, sorts each conflicted file by difficulty, and stops only when a decision really belongs to a person.

How a pull request moves

The loop runs by itself, in the agent session you already use. It asks you only when the budget of automatic cycles is spent or a decision belongs to you.

Start in four steps

  1. Install. From a release clone: ./install.sh --harness claude-code --yes. Other harnesses use their own flag.
  2. Prepare the repository once. Set REVIEW_MARKER_AUTHORS to your GitHub login, then run review-cycle.sh ensure-labels.
  3. Open a draft pull request. The agent in your session starts the loop without being asked.
  4. Read the report. The first comment says who wrote it, what passed, what blocks, and what to read first.

Built to be checked

No model in CI

No GitHub Actions workflow calls a model. The review and the fix run in your own session, with your own authentication.

Trust by login

Only comments from logins you name count as reports. An edited comment never counts as a verdict.

No silent merges

The skills never merge, approve, tag or release. Automatic reviews never request changes on GitHub.

Tests that run offline

The scripts have a test suite that runs against a fake gh. Nothing touches GitHub while it runs.
